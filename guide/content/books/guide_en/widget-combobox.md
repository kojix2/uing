# Combobox

[日本語](../guide_ja/widget-combobox.html)

Combobox lets the user choose one item from a fixed list.

## Usage notes

- Use <code>selected</code> and <code>selected=</code> with zero-based indices.
- Items can be appended, inserted, deleted, or cleared.
