# Combobox

[English](../guide_en/widget-combobox.html)

Comboboxは固定された一覧から1項目を選択するコントロールです。

{{% shell command="sh scripts/render-example basic_combobox" %}}

## 使い方

- 選択位置は0始まりの<code>selected</code>と<code>selected=</code>で扱います。
- 項目の追加、挿入、削除、全削除ができます。
